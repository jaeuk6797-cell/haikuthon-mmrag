# `sub_v9_blipA.zip` 과 `sub_v9.zip` 비교

작성: 2026-11-22 07:00 · 두 ZIP은 Release `v9`에 있습니다.

## 결론

**`sub_v9_blipA.zip`이 더 적절합니다.** 두 파일은 BLIP 가중치 하나만 다르고, blipA는 리더보드에서 검증된 BLIP을 씁니다. `sub_v9.zip`의 BLIP은 v7에서 리더보드 점수를 떨어뜨린 모델입니다.

다만 이 판단은 v7의 결과와 로컬 실험에 근거한 것이고, 두 ZIP을 직접 비교한 리더보드 점수는 아직 없습니다. 둘 다 제출해서 높은 쪽을 최종으로 삼는 것이 가장 확실합니다.

## 무엇이 다른가

ZIP 안의 24개 파일 중 **`models/blip/model.safetensors` 1개만 다릅니다.** 코드, 설정, SigLIP, OWL은 같습니다.

## 왜 blipA가 더 적절한가

1. **D의 로컬 이득은 오차 범위 수준이었습니다.** 개발 +0.006, 검증 +0.005입니다. 검증 800개 기준으로는 우연으로도 나올 수 있는 크기입니다.
2. **v7은 리더보드에서 떨어졌습니다.** v7은 v6에서 BLIP을 D로 바꾸고 복수 관계 점검을 더한 것입니다.
3. **v7의 제출 CSV를 v6와 비교하면 BLIP이 순서를 크게 뒤집었습니다.**
   - 후보 범위는 같습니다 (5장 중 4장 이상 같은 질의 91%).
   - 그런데 1위가 2,445개(30.6%) 바뀌었습니다. 바뀐 1위의 95%는 v6의 5장 안에 있던 이미지입니다.
   - 서로 다른 1위 이미지 수가 5,152 → 5,107로 줄었습니다 (여러 질의가 같은 이미지를 1위로 고르는 일이 늘어남).
4. **D는 학습 이미지를 더 강하게 외웁니다.** 학습에 쓴 큰 형제 묶음 140질의에서 1위 정답이 D 139개, A 124개였습니다. 이미지 인코더까지 학습한 영향이며, 처음 보는 테스트 이미지에는 그만큼 통하지 않은 것으로 판단합니다.
5. **SigLIP 학습의 이득은 BLIP과 무관합니다.** 두 ZIP 모두 같은 SigLIP을 쓰므로, 이 이득은 어느 쪽에서도 얻습니다.

## 확인한 것

| 항목 | `sub_v9_blipA.zip` | `sub_v9.zip` |
|---|---|---|
| ZIP 내용 대조 | v9와 BLIP 가중치만 다름, BLIP이 v6의 것과 일치, SigLIP이 v9의 것과 일치, 압축 손상 없음 | 셀 16이 만든 그대로 |
| 실행 점검 | PC에서 ZIP 그대로 풀어 실행: 형식 정상, BLIP 후보 10장, OWL·복수 관계 동작 | Kaggle에서 후보 4,000장으로 실행: 형식 정상, 개발 0.9638 / 검증 0.9705 |

- 실행 점검의 점수는 BLIP이 해당 질의를 학습에 쓴 상태라 실제보다 높습니다. 정상 동작 확인용입니다.
- 두 ZIP의 리더보드 점수는 제출 후 이 문서에 추가합니다.

## 남은 불확실성

- v7의 하락 폭이 작다면 우연일 가능성도 있습니다. Public 점수는 테스트의 40%로 계산되어 ±0.008 정도는 흔들릴 수 있습니다.
- v7에는 D와 복수 관계 점검이 함께 들어갔습니다. 복수 관계 점검은 대상이 전체의 약 5%이고 로컬에서 고침 4건·망침 0건이라 영향이 작다고 보지만, 리더보드에서 따로 확인하지는 않았습니다. 두 ZIP 모두 복수 관계 점검이 켜져 있습니다.
