# v7 전략 정리 (v4 → v6 → v7)

작성: 2026-11-22 · 기준: `sub_v7.zip`의 `models/haiku_config.json`, `model.py`

## 1. 파이프라인

```
질의 문장
 → SigLIP-base-384 검색 (상위 10장)
 → 조건 분해 재정렬 (조건 12종, 비중 3.2)
 → 학습한 BLIP ITM 재정렬 (10장 전부, 점수 비중 0.1)
 → OWL-ViT 좌우·상하 점검 (상위 2장, 확신도 0.1 / 여백 0.06)
 → 복수 관계 점검 (상위 2장, "두 X가 한 Y의 위·아래·왼쪽·오른쪽" 문장만)
 → 상위 5장
```

## 2. 버전별 변화와 리더보드

| 버전 | 바뀐 것 | Public |
|---|---|---|
| v4 | SigLIP + 조건 재정렬 + BLIP(상위 5장) + OWL 좌우·상하 | 0.3355 |
| v5 | OWL 관계 확장 (위에 놓임·안·타기·옆) | v4보다 하락 → 되돌림 |
| v6 | **BLIP 후보 5장 → 10장**, 시간 안전장치를 경과 시간 기준으로 교체 | **0.3640** (R@1 0.2769, R@5 0.6056, NDCG@5 0.4510) |
| v7 | **BLIP 학습 개선(D) + 복수 관계 점검** | 제출 예정 |

- v6 → v7에서 SigLIP·OWL 가중치는 그대로이고 BLIP 가중치만 새로 학습했습니다.

## 3. v7에 들어간 것과 근거

검증 방식: 형제 묶음 단위 분할 (학습 2,724 / 개발 476 / 검증 800). 값은 개발에서 고르고 검증은 보고만 합니다. **개발·검증 둘 다 좋아질 때만** 반영합니다.

### 3-1. BLIP 학습 D

| 항목 | 기존 (v4·v6) | D (v7) |
|---|---|---|
| 학습하는 부분 | 문장 인코더 + 매칭 헤드 | + **이미지 인코더 마지막 2층**, 출력 정규화층 |
| 오답 이미지 | 형제 이미지 7장 | **검색 후보 9장** (SigLIP 검색 + 조건 재정렬 상위 10장 중 정답 제외) |
| 학습률 | 2e-5 | 문장 쪽 2e-5, 이미지 쪽 1e-5 |
| 에폭 / 스텝당 질의 | 3 / 8 | 3 / 8 (2개씩 나눠 계산 후 한 번에 갱신) |

| | 개발 | 검증 |
|---|---|---|
| 기존 | 0.8396 | 0.8307 |
| D | 0.8459 (+0.006) | 0.8356 (+0.005) |

### 3-2. 복수 관계 점검 (팀원 방법)

- 대상: "두 X가 한 Y의 위/아래/왼쪽/오른쪽" 문장. 기존 OWL 점검은 같은 종류가 여러 개면 건너뛰었습니다.
- 파서(`parse_plural_plan`)와 상자 판정(`plural_geometry`, 여백 0.08)은 팀원 원 실험 코드를 그대로 사용했고, 검출기만 Grounding DINO → 이미 탑재된 OWL-ViT(여러 상자)로 바꿨습니다.
- 주체 상자가 정확히 2개, 기준 상자가 정확히 1개일 때만 판정하고, **1위가 위반이고 2위가 만족일 때만** 교환합니다.

| | 대상 문장 | 교환 | 고침 | 망침 |
|---|---|---|---|---|
| 개발 | 22 | 1 | 1 | 0 |
| 검증 | 37 | 3 | 3 | 0 |

## 5. 분석으로 알게 된 것

- **테스트의 형제 묶음은 약 40~64장** (제출 CSV에서 함께 예측된 이미지를 묶어 추정). 학습 데이터는 4장 또는 8장입니다.
- v6 테스트 결과: 정답이 5위 안에 드는 비율 61%, 그 안에서 1위로 고르는 비율 46% (로컬 검증은 99%, 78%).
- 검색과 조건 재정렬을 맡는 SigLIP은 사전학습 그대로입니다. 이 부분을 학습하는 실험(형제 묶음 배치 + 조건 문구 학습)이 진행 중입니다.
- 팀원 실험 결과(`sibling_results.zip`)를 다시 계산해 보면, S0와 S1의 점수를 합쳤을 때 1위 정답이 527 → 547로 늘어납니다 (0.7564 → 0.7750). 다르게 학습한 재정렬 모델 둘을 합치는 방향이 유효하다는 근거입니다.

## 6. 규칙 점검

- 추론 중 외부 API·생성형 LLM 없음, 외부 데이터 없음 (공개 사전학습 가중치만 사용).
- 질의마다 독립적으로 예측합니다. 다른 질의의 예측이나 점수 분포로 조정하지 않습니다.
- 모든 단계는 모든 질의에 같은 기준으로 적용합니다 (애매한 질의만 골라 추가 보정하지 않음).
- 시간 안전장치는 경과 시간만 사용합니다.
- 학습은 제공된 4,000쌍과 그 규칙 기반 변형만, 무료 Kaggle GPU 1장에서 했습니다.
